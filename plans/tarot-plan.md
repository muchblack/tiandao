## Requirements Summary

### Problem Statement

天道 LINE bot 已有 5 項占卜服務（起卦／抽神社籤／大樂透號碼／蒙地卡羅預測／小六壬），尚無視覺化占卜。塔羅以 78 張公有領域牌面圖（RWS 1909）配合牌意文字，提供圖文雙呈現的占卜體驗，補足專案視覺空缺。

### Scope

**In scope**：

- 新增 `Tarot` Command，雙關鍵字觸發
- 78 張全牌庫 × 含正逆位
- 每日塔羅：抽 1 張，回 ImageMessage + TextMessage
- 三牌陣：抽 3 張不重複，回 FlexCarousel + TextMessage
- 78 張 PD 牌面圖入 `public/img/tarot/`

**Out of scope**：

- 使用者抽牌記錄持久化
- 凱爾特十字等複雜陣法
- 接受使用者問題輸入
- 重繪牌面（直接用 RWS 1909 PD 原版）

- [ ] 兩個關鍵字皆能路由至 Tarot
- [ ] 每日塔羅回 ImageMessage + TextMessage 共 2 條
- [ ] 三牌陣回 FlexCarousel + TextMessage 共 2 條
- [ ] 三牌陣不重複（單元測試守護）
- [ ] 78 張圖在 `public/img/tarot/` 可訪問且 ≤1MB
- [ ] `php artisan test` 全綠

### Constraints

- Command 介面相容（canHandle/handle/getDescription/replyCommand）
- LINE replyMessage 5 條上限 → 三牌陣用 FlexCarousel 壓縮成 2 條
- 圖片走 Laravel `public/`，URL 由 `asset()` 產生
- 嚴格用 RWS 1909 PD 原版，禁用 U.S. Games 1971 改版

### Assumptions

- 系統時區為 `Asia/Taipei`（已於小六壬任務確認）
- staging 環境 `APP_URL` 為 LINE 可訪問的 HTTPS 公開 URL
- ImageMagick 已安裝於 podman php-fpm 容器（待 Step 3 驗證）

## Architecture

### Command 設計

`Tarot` 實作 `Command` 介面：

- `canHandle()`：接受 `每日塔羅` / `塔羅三牌陣`
- `handle()` / `replyCommand()`：依關鍵字分派
    - `每日塔羅` → `drawDaily()` → `[ImageMessage, TextMessage]`
    - `塔羅三牌陣` → `drawThreeCard()` → `[FlexMessage, TextMessage]`
- `getDescription()`：簡述

### 牌庫資料 `data/tarot/cards.json`

陣列 78 個物件，每物件：

```json
{
  "id": 0,
  "arcana": "major",
  "suit": null,
  "name_zh": "愚者",
  "name_en": "The Fool",
  "image": "00.jpg",
  "upright":  { "keywords": ["關鍵字..."], "summary": "一句概述", "meaning": "2-3 句綜合詮釋" },
  "reversed": { "keywords": [...], "summary": "...", "meaning": "..." }
}
```

ID 對應規則：

| ID 範圍 | 牌組         | 檔名            |
| ------- | ------------ | --------------- |
| 00-21   | 大阿爾克那   | 00.jpg ~ 21.jpg |
| 22-35   | Wands 01-14  | 22.jpg ~ 35.jpg |
| 36-49   | Cups 01-14   | 36.jpg ~ 49.jpg |
| 50-63   | Swords 01-14 | 50.jpg ~ 63.jpg |
| 64-77   | Pents 01-14  | 64.jpg ~ 77.jpg |

### 抽牌邏輯

```
drawDaily():
  card = random_int(0, 77)
  reversed = random_int(0, 1) === 1
  return [card, reversed]

drawThreeCard():
  cards = array_rand(range(0, 77), 3)  // 保證不重複
  reversed = [random_int(0, 1) === 1 for each card]
  return [(card_i, reversed_i) for i in 0..2]
```

### Flex Carousel 結構（三牌陣）

```
FlexCarouselContainer
├── FlexBubble #0（過去）
│   ├── Hero: FlexImage (aspectRatio 2:3, size full)
│   └── Body: FlexBox (vertical)
│       ├── FlexText "過去" (weight bold)
│       └── FlexText 牌名+正逆位
├── FlexBubble #1（現在）
│   └── ... 同上
└── FlexBubble #2（未來）
    └── ... 同上
```

`FlexMessage altText` = `「塔羅三牌陣：過去/現在/未來」`（使用者收到通知欄看到）。

### 圖片下載與壓縮

`scripts/fetch-tarot-images.sh`：

1. 列舉 78 個 Wikimedia Commons 檔名 → URL（Special:FilePath）
2. `curl` 下載至 `tmp/tarot-raw/`，每張間 sleep 1.5 秒避 429
3. `ImageMagick convert` resize 600x、quality 85 → `public/img/tarot/NN.jpg`
4. 已存在則 skip（支援續傳）
5. 結尾驗證：78 個檔案、單檔 ≤ 1MB

## Technical Considerations

- **LINE Image 規格**：原始圖 max 1024×1024 / max 10MB；預覽 max 240×240 / max 1MB。我們壓縮至 600×... 同檔同 URL，預覽由 LINE 自動產生。
- **Flex Bubble 資料量**：單個 carousel 上限 50KB（JSON），3 bubble 平均 15KB 內；中文不會超。
- **抽牌隨機性測試**：用 `mt_srand(seed)` 固定種子驗證輸出，不暴露 random source 也行。
- **三牌陣不重複**：用 `array_rand($all_cards, 3)` 內建保證，再加 `assertCount(3, array_unique($drawn))` 守護。
- **ImageMagick**：podman php-fpm 容器需有 `convert`。Step 3 起手先 `which convert` 驗證。
- **APP_URL 與圖片可訪問性**：staging/prod 的 `config('app.url')` 必須是 LINE 服務可達的 HTTPS。本地 ngrok / cloudflare tunnel 為退路。

## Risk Management

| Risk                     | Impact | Likelihood | Mitigation                                                                   |
| ------------------------ | ------ | ---------- | ---------------------------------------------------------------------------- |
| 78 張資料撰寫工作量大    | High   | High       | 結構化 JSON 模板先建立 schema，再逐張填寫；keywords 短、meaning 控制 80 字內 |

| 抽到非 PD 改版圖         | High   | Low        | URL 已逐張驗證為 1909 原版檔名；下載後 hash 比對                             |
| ImageMagick 容器內無     | Med    | Med        | Step 3 起手 `which convert`，缺則 `apk add imagemagick` 或本機壓縮           |
| Flex JSON 結構手寫易出錯 | Med    | Med        | 用 LINE SDK 的 PHP 物件層而非手寫 JSON；單元測試守護 bubble 數=3             |
| LINE staging 收不到圖    | High   | Med        | Step 11 manual gate 真機驗證；ngrok 退路                                     |
| 圖片 cache 影響後續更新  | Low    | Med        | URL 加版本參數 `?v=NN` 強刷快取（日後若改圖時再啟用）                        |

### Alternative Approaches Considered

1. **單一 ImageCarouselTemplate**：1:1 強制裁切會切掉塔羅 2:3 上下；捨棄。
2. **CarouselTemplate 含 title + text**：縮圖也是 1:1；捨棄。

5. **下載至 CDN**：複雜度高、成本未知；捨棄（先放 git，超量再轉）。

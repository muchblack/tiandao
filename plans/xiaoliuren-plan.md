## Requirements Summary

### Problem Statement

天道 LINE bot 現有四項占卜服務（起卦、抽神社籤、大樂透號碼、蒙地卡羅預測），尚缺一項簡明快速的問事占卜法。小六壬以六宮循環推演，演算法古老而標準化，適合作為輕量級補充。

**In scope**:

## Architecture

### Approach

**演算法（小六壬正統）**：

六宮循環順序：**大安 → 留連 → 速喜 → 赤口 → 小吉 → 空亡**

| 宮 | 起算點 | 步進量 |
|----|--------|--------|
| 月宮 | 大安（index 0） | 農曆月 M（1-12），結果 = (M-1) % 6 |
| 日宮 | 月宮 | 農曆日 D（1-30），結果 = (月宮 + D - 1) % 6 |
| 時宮 | 日宮 | 時辰序 H（子=1...亥=12），結果 = (日宮 + H - 1) % 6 |

時辰由 `\Lunar\Lunar::fromDate(new DateTime())->getTimeZhi()` 取地支字元，再對映 1-12。

### Key Components

- **`app/KeyWords/XiaoLiuRen.php`**: Command 實作。封裝六宮順序、時辰映射、起卦邏輯、回覆組裝。
- **`data/xiaoLiuRen/palaces.json`**: 六宮資料字典。每宮含 name / wuxing / direction / summary / aspects（事業/愛情/出行/失物/疾病/求財）。
- **`tests/Unit/KeyWords/XiaoLiuRenTest.php`**: 單元測試，固定日期釘死演算法輸出。

### Data Flow

```
LINE webhook
   │
   ▼
EventProcessor.processWebhook
   │
CommandRegistry.findCommand("小六壬")
   │
   ▼
XiaoLiuRen.handle(MessageEvent)
   │
   ├─ Lunar::fromDate(now()) → 月M / 日D / 時辰地支
   │
   ├─ 計算月宮 / 日宮 / 時宮 (mod 6)
   │
   ├─ 讀 palaces.json 取卦意
   │
   └─ 回 [TextMessage(月宮), TextMessage(日宮), TextMessage(時宮)]
```

## Technical Considerations

- **時辰邊界**：23:00-00:59 屬子時但跨日，`6tail/lunar-php::fromDate()` 已處理；不可自寫小時除法。
- **農曆閏月**：本演算法不區分閏月，依套件回傳的 `getMonth()`（1-12）即可。
- **時區**：Laravel 預設 `app.timezone` 為 `UTC`，需確認專案設定為 `Asia/Taipei`，或在類別內顯式 `setTimezone`。
- **PHP 8.4 相容性**：`6tail/lunar-php` 應支援，Step 1 安裝即驗證。若不相容則考慮 fork 或改用 `overtrue/chinese-calendar` + 自寫時辰映射。
- **JSON 編碼**：palaces.json 含中文，須以 UTF-8 儲存且不轉義（`JSON_UNESCAPED_UNICODE`）。
